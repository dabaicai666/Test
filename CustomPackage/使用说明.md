# Xreal 手势检测使用指南

## 简介

本手势检测系统基于 Unity XR Hands 1.4.3 开发，专为 Xreal SDK 3.1.0 设计。提供简单易用的 API 来检测常见的手势操作。

## 环境要求

- Unity 2021.3 或更高版本
- XR Hands: 1.4.3
- XR Interaction Toolkit: 2.6.5
- Xreal XR Plugin: 3.0.0
- Xreal SDK: 3.1.0

## 安装步骤

1. 将 `CustomPackage` 文件夹导入到您的 Unity 项目中
2. 确保已安装 XR Hands 包（通过 Package Manager）
3. 确保项目中已正确配置 Xreal XR Plugin

## 核心组件

### HandGestureDetector（手势检测器）

这是主要的手势检测组件，负责实时检测手部手势。

#### 支持的手势类型

| 手势类型 | 描述 | 检测条件 |
|---------|------|---------|
| **Fist** | 拳头 | 所有手指都弯曲 |
| **Grab** | 抓取 | 四指弯曲（类似抓握动作） |
| **Pinch** | 捏合 | 大拇指和食指尖距离很近 |
| **OpenHand** | 张开手掌 | 所有手指伸直 |
| **ThumbsUp** | 竖大拇指 | 大拇指伸直，其他手指弯曲 |
| **Point** | 指向 | 食指伸直，其他手指弯曲 |

## 使用方法

### 方法一：使用事件系统（推荐）

这是最常用的方式，当检测到手势时会自动触发回调。

```csharp
using UnityEngine;
using UnityEngine.XR.Hands;
using XrealHandGesture;

public class MyGestureController : MonoBehaviour
{
    private HandGestureDetector gestureDetector;

    void Start()
    {
        // 获取手势检测器组件
        gestureDetector = GetComponent<HandGestureDetector>();
        
        // 订阅手势事件
        gestureDetector.OnGestureDetected += HandleGestureDetected;
        gestureDetector.OnGestureEnded += HandleGestureEnded;
    }

    void OnDestroy()
    {
        // 取消订阅（重要！防止内存泄漏）
        if (gestureDetector != null)
        {
            gestureDetector.OnGestureDetected -= HandleGestureDetected;
            gestureDetector.OnGestureEnded -= HandleGestureEnded;
        }
    }

    // 手势开始时调用
    private void HandleGestureDetected(GestureType gesture, Handedness hand)
    {
        Debug.Log($"检测到 {hand} 手的 {gesture} 手势");
        
        // 根据手势类型执行不同操作
        switch (gesture)
        {
            case GestureType.Fist:
                OnFist(hand);
                break;
            case GestureType.Grab:
                OnGrab(hand);
                break;
            case GestureType.Pinch:
                OnPinch(hand);
                break;
            // ... 其他手势
        }
    }

    // 手势结束时调用
    private void HandleGestureEnded(GestureType gesture, Handedness hand)
    {
        Debug.Log($"{hand} 手的 {gesture} 手势结束");
    }

    private void OnFist(Handedness hand)
    {
        // 拳头手势的处理逻辑
        // 例如：触发攻击动作
    }

    private void OnGrab(Handedness hand)
    {
        // 抓取手势的处理逻辑
        // 例如：抓取物体
    }

    private void OnPinch(Handedness hand)
    {
        // 捏合手势的处理逻辑
        // 例如：精确选择UI
    }
}
```

### 方法二：主动查询

在 Update 中主动查询当前的手势状态。

```csharp
using UnityEngine;
using XrealHandGesture;

public class GestureQuery : MonoBehaviour
{
    private HandGestureDetector gestureDetector;

    void Start()
    {
        gestureDetector = GetComponent<HandGestureDetector>();
    }

    void Update()
    {
        // 查询当前手势
        GestureType leftGesture = gestureDetector.GetCurrentLeftHandGesture();
        GestureType rightGesture = gestureDetector.GetCurrentRightHandGesture();

        // 检查特定手势是否正在执行
        if (gestureDetector.IsGestureActive(GestureType.Pinch, Handedness.Right))
        {
            // 右手正在执行捏合手势
            // 持续执行某个操作
            DoPinchAction();
        }

        // 检查双手手势组合
        if (leftGesture == GestureType.Fist && rightGesture == GestureType.Fist)
        {
            // 双手都是拳头
            DoSpecialAction();
        }
    }

    private void DoPinchAction()
    {
        // 捏合时持续执行的操作
    }

    private void DoSpecialAction()
    {
        // 双手拳头的特殊操作
    }
}
```

## 实际应用场景

### 场景1：物体抓取系统

```csharp
public class ObjectGrabber : MonoBehaviour
{
    private HandGestureDetector gestureDetector;
    private GameObject grabbedObject;
    private Transform rightHandTransform;

    void Start()
    {
        gestureDetector = GetComponent<HandGestureDetector>();
        gestureDetector.OnGestureDetected += OnGestureDetected;
        gestureDetector.OnGestureEnded += OnGestureEnded;
    }

    private void OnGestureDetected(GestureType gesture, Handedness hand)
    {
        if (gesture == GestureType.Grab && hand == Handedness.Right)
        {
            // 尝试抓取附近的物体
            TryGrabNearbyObject();
        }
    }

    private void OnGestureEnded(GestureType gesture, Handedness hand)
    {
        if (gesture == GestureType.Grab && hand == Handedness.Right)
        {
            // 释放物体
            ReleaseObject();
        }
    }

    private void TryGrabNearbyObject()
    {
        // 在手部附近搜索可抓取的物体
        Collider[] colliders = Physics.OverlapSphere(rightHandTransform.position, 0.1f);
        foreach (var col in colliders)
        {
            if (col.CompareTag("Grabbable"))
            {
                grabbedObject = col.gameObject;
                grabbedObject.transform.SetParent(rightHandTransform);
                break;
            }
        }
    }

    private void ReleaseObject()
    {
        if (grabbedObject != null)
        {
            grabbedObject.transform.SetParent(null);
            grabbedObject = null;
        }
    }
}
```

### 场景2：菜单系统控制

```csharp
public class MenuController : MonoBehaviour
{
    private HandGestureDetector gestureDetector;
    [SerializeField] private GameObject menuPanel;
    private bool isMenuOpen = false;

    void Start()
    {
        gestureDetector = GetComponent<HandGestureDetector>();
        gestureDetector.OnGestureDetected += OnGestureDetected;
    }

    private void OnGestureDetected(GestureType gesture, Handedness hand)
    {
        if (hand != Handedness.Left) return; // 只响应左手

        switch (gesture)
        {
            case GestureType.OpenHand:
                // 张开手掌打开菜单
                OpenMenu();
                break;
            
            case GestureType.Fist:
                // 握拳关闭菜单
                CloseMenu();
                break;
            
            case GestureType.ThumbsUp:
                // 竖大拇指确认选择
                ConfirmSelection();
                break;
            
            case GestureType.Point:
                // 食指指向进行选择
                PointAndSelect();
                break;
        }
    }

    private void OpenMenu()
    {
        if (!isMenuOpen)
        {
            menuPanel.SetActive(true);
            isMenuOpen = true;
        }
    }

    private void CloseMenu()
    {
        if (isMenuOpen)
        {
            menuPanel.SetActive(false);
            isMenuOpen = false;
        }
    }

    private void ConfirmSelection()
    {
        // 确认当前选择的菜单项
        Debug.Log("确认选择");
    }

    private void PointAndSelect()
    {
        // 使用射线检测指向的菜单项
        Debug.Log("指向选择");
    }
}
```

### 场景3：游戏控制（射击游戏）

```csharp
public class ShootingController : MonoBehaviour
{
    private HandGestureDetector gestureDetector;
    [SerializeField] private GameObject bulletPrefab;
    [SerializeField] private Transform firePoint;
    
    private bool isShooting = false;
    private float lastFireTime;
    private float fireRate = 0.5f; // 每0.5秒可以射击一次

    void Start()
    {
        gestureDetector = GetComponent<HandGestureDetector>();
    }

    void Update()
    {
        // 右手做指向手势时进行射击
        if (gestureDetector.IsGestureActive(GestureType.Point, Handedness.Right))
        {
            if (Time.time - lastFireTime > fireRate)
            {
                Fire();
                lastFireTime = Time.time;
            }
        }

        // 右手做拳头手势时进行近战攻击
        if (gestureDetector.IsGestureActive(GestureType.Fist, Handedness.Right))
        {
            MeleeAttack();
        }
    }

    private void Fire()
    {
        // 发射子弹
        GameObject bullet = Instantiate(bulletPrefab, firePoint.position, firePoint.rotation);
        Rigidbody rb = bullet.GetComponent<Rigidbody>();
        rb.velocity = firePoint.forward * 20f;
        
        Debug.Log("开火！");
    }

    private void MeleeAttack()
    {
        // 近战攻击逻辑
        Debug.Log("近战攻击！");
    }
}
```

## 参数调整

在 Unity Inspector 中，`HandGestureDetector` 组件提供以下可调参数：

### 基本设置
- **Detect Left Hand**: 是否检测左手（默认开启）
- **Detect Right Hand**: 是否检测右手（默认开启）

### 阈值参数
- **Curl Threshold** (弯曲阈值): 0-1，默认 0.7
  - 数值越大，手指需要弯曲得越厉害才会被识别为弯曲状态
  - 建议范围：0.6-0.8

- **Pinch Threshold** (捏合阈值): 米，默认 0.03
  - 大拇指和食指尖的最大距离，小于此值才识别为捏合
  - 建议范围：0.02-0.05

- **Straight Threshold** (伸直阈值): 0-1，默认 0.5
  - 数值越小，手指需要伸得越直才会被识别为伸直状态
  - 建议范围：0.3-0.6

### 调整建议

如果手势识别不准确，可以尝试调整这些参数：

1. **手势太容易触发**：增加对应的阈值
2. **手势不容易触发**：降低对应的阈值
3. **误识别太多**：增加阈值，使检测更严格
4. **识别不灵敏**：降低阈值，使检测更宽松

## 常见问题

### Q: 手势检测不工作？
A: 检查以下几点：
1. 确保场景中已添加 `HandGestureDetector` 组件
2. 确保已安装 XR Hands 包
3. 确保 Xreal 设备支持手部追踪
4. 查看 Console 是否有 "Hand Subsystem 已初始化" 的日志

### Q: 手势识别不准确？
A: 可以尝试：
1. 调整 Inspector 中的阈值参数
2. 确保手部在设备的追踪范围内
3. 确保光线条件良好
4. 手势动作要标准清晰

### Q: 如何只检测单手？
A: 在 Inspector 中取消勾选不需要检测的手：
- 只检测右手：取消勾选 "Detect Left Hand"
- 只检测左手：取消勾选 "Detect Right Hand"

### Q: 可以自定义手势吗？
A: 可以！在 `HandGestureDetector.cs` 中添加新的检测方法：

```csharp
// 添加到 DetectGesture 方法中
if (IsMyCustomGesture(hand)) return GestureType.MyCustom;

// 添加自定义手势检测方法
private bool IsMyCustomGesture(XRHand hand)
{
    // 实现你的手势检测逻辑
    // 例如：检测特定手指的组合状态
    return IsFingerStraight(hand, XRHandFingerID.Index) &&
           IsFingerStraight(hand, XRHandFingerID.Middle) &&
           IsFingerCurled(hand, XRHandFingerID.Ring);
}
```

## 性能优化建议

1. **按需检测**：如果只需要检测单手，关闭另一只手的检测
2. **事件优于轮询**：优先使用事件系统而不是在 Update 中不断查询
3. **降低检测频率**：如果不需要实时响应，可以每隔几帧检测一次
