# 快速开始 - 5分钟上手手势检测

## 第一步：创建场景

1. 在 Unity 中创建一个新场景
2. 确保场景已配置好 Xreal XR Plugin

## 第二步：添加手势检测器

1. 在场景中创建一个空物体（GameObject > Create Empty）
2. 命名为 "GestureManager"
3. 添加 `HandGestureDetector` 组件

## 第三步：创建控制脚本

创建一个新脚本 `MyFirstGesture.cs`：

```csharp
using UnityEngine;
using UnityEngine.XR.Hands;
using XrealHandGesture;

public class MyFirstGesture : MonoBehaviour
{
    private HandGestureDetector detector;

    void Start()
    {
        detector = GetComponent<HandGestureDetector>();
        detector.OnGestureDetected += OnGesture;
    }

    private void OnGesture(GestureType gesture, Handedness hand)
    {
        Debug.Log($"{hand}手做了{gesture}手势！");
    }
}
```

## 第四步：测试

1. 将 `MyFirstGesture.cs` 添加到 GestureManager 物体上
2. 运行场景
3. 在设备上做出不同的手势（拳头、张开手掌等）
4. 查看 Console 输出

## 常用手势

试试这些手势：

| 手势 | 做法 |
|-----|------|
| **Fist** | 握紧拳头 |
| **OpenHand** | 张开五指 |
| **Pinch** | 大拇指和食指捏在一起 |
| **Point** | 伸出食指，其他手指弯曲 |
| **ThumbsUp** | 竖大拇指 |
| **Grab** | 四指弯曲做抓握动作 |

## 简单示例：做拳头物体变红

```csharp
using UnityEngine;
using UnityEngine.XR.Hands;
using XrealHandGesture;

public class ColorChanger : MonoBehaviour
{
    [SerializeField] private GameObject targetObject;
    private HandGestureDetector detector;
    private Renderer targetRenderer;

    void Start()
    {
        detector = GetComponent<HandGestureDetector>();
        detector.OnGestureDetected += OnGesture;
        
        if (targetObject != null)
            targetRenderer = targetObject.GetComponent<Renderer>();
    }

    private void OnGesture(GestureType gesture, Handedness hand)
    {
        if (targetRenderer == null) return;

        switch (gesture)
        {
            case GestureType.Fist:
                targetRenderer.material.color = Color.red;
                break;
            case GestureType.OpenHand:
                targetRenderer.material.color = Color.green;
                break;
            case GestureType.Pinch:
                targetRenderer.material.color = Color.blue;
                break;
        }
    }
}
```

就是这么简单！现在开始创建您自己的手势交互吧！
